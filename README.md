Classical Arabic TDA: Multi-Scale Topological Data Analysis of Macro-Structural SymmetriesThis repository contains the data, Python pipeline, and computational results for the quantitative analysis of macro-structural symmetries (ring composition) in classical Arabic corpora.The project applies a combination of Natural Language Processing (NLP) and Topological Data Analysis (TDA) to evaluate the structural architecture of the ten longest chapters (Surahs) of the Quran, proving mathematically that their geometric symmetry is intentional and statistically distinct from random vocabulary distribution.How the Pipeline WorksTo measure the "shape" of a text, we cannot just count words. Classical Arabic is highly inflected, meaning the same theme can be expressed using entirely different vocabulary derived from various root structures. This pipeline translates abstract literary concepts into a rigorous mathematical framework through five distinct steps:1. Morphological PreprocessingRaw classical Arabic text is morphologically dense. We use the Farasa segmenter via the ArabertPreprocessor to isolate prefixes, stems, and suffixes. This ensures the transformer model understands the foundational root meanings of the words rather than getting confused by structural attachments.2. Semantic Vectorization & CompressionWe feed the segmented text into AraBERTv02. AraBERT maps every verse into a 768-dimensional space, where verses with similar meanings are grouped closer together.However, 768 dimensions contain too much lexical noise for geometry calculations. We use Principal Component Analysis (PCA) to compress these vectors down to the 20 most important thematic dimensions, followed by $L_2$ normalization to project the data onto a uniform geometric sphere.3. Tracking the Narrative Flow (Time-Delay Embedding)Standard math treats text as a bag of isolated points. But a story is a sequence. We adapt Takens' Time-Delay Embedding Theorem to capture the narrative trajectory. Instead of looking at one verse at a time, we look at "sliding windows" of text (e.g., 15, 20, or 30 verses at a time). As the window slides forward, it traces a continuous, multi-dimensional path of the text's overarching themes.4. Finding the Shape (Topological Data Analysis)If "ring composition" is real, the text's path will eventually loop back to where it started. We use the Vietoris-Rips filtration (via the ripser library) to calculate the distance between these sliding windows using Cosine Distance. We track the birth and death of $H_1$ topological features. An $H_1$ feature is simply a mathematical loop. The longer a loop persists without closing, the stronger the structural symmetry of the text.5. Statistical Proof (Monte Carlo Simulation)How do we know these loops aren't just a coincidence? We take the exact same verses from the text and randomly shuffle them 100 times. We run the entire TDA pipeline on these random shuffles to find the "noise" baseline. We then calculate a standard $Z$-score. In our study, texts like Surah Ash-Shu'ara produced a $Z$-score of 22.64—meaning it is statistically impossible for its geometric symmetry to be an accident.Repository Structurenotebooks/: Contains the Jupyter Notebooks with the complete, step-by-step pipeline.data/: Contains the morphological text inputs and the resulting statistical datasets (e.g., quran_tda_multisurah_results.csv).visualizations/: Generated heatmaps, maximum peak charts, and persistence diagrams.requirements.txt: List of required Python libraries to reproduce the environment.Installation and RequirementsTo run this pipeline locally, you need Python 3.8+ and the following core libraries:Bashgit clone https://github.com/raadbintareaf/Classical-Arabic-TDA.git
